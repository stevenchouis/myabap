# 表單設計練習 7：套表列印（中一刀連續紙套版）

## Lecture

sf01～sf06 教的都是「從零設計一張單據」：自己畫 Logo、自己畫框線、自己排表格。但很多真實客戶場景是反過來的——**客戶已經有印好格線、印好欄位名稱的制式紙本**（最常見的就是連續紙複寫套表，多聯發票、出貨單、簽收單），Smartform 只需要**精準把資料印到既有的空格裡**，不能再畫任何框線或標題文字（紙上早就有了，重複印上去只會變成疊字、模糊）。這題教這個反過來的技巧：**套表列印**。

**先釐清一個容易搞混的概念**：中一刀連續紙這種「一次列印、三聯同時複寫」的效果，是**印表機物理壓力／複寫紙結構**造成的——型打式（點矩陣）印表機的打字頭撞擊力道穿透三層複寫紙，三份同時印出來，這件事**跟 SAP 對印句數完全無關**，印表機收到的還是「印一份」的指令。這一定要跟 sf02 教過的 **Copies Window** 分清楚：Copies Window 是「同一個列印工作要求系統重複輸出好幾份、每份內容甚至可以不同（例如正本印公司抬頭、副本印『此聯僅供內部存查』）」，是**邏輯層面**的重複列印，跟中一刀複寫紙這種**物理層面**的一次成型是兩回事——不要把「三聯」誤會成要在 Smartform 裡設定印三次。

**套表列印的核心技巧：只定位、不畫圖**：

- 前六題教的 Box and Shading（sf04）、Template 格線，這題**完全不用**——紙上已經有格線跟欄位標題了，Smartform 只放**不帶任何框線/網底**的 Text 節點，精準對齊到空格中央或起始點
- 位置的量測方法沿用 sf02 教過的「用數字精確輸入 Window 的 Position／Size」，但反過來用：不是自己決定版面要多大，是**照著客戶紙本上既有格子的實際位置去量、去對**
- **校準是反覆試印的過程**：印一張測試頁在空白紙上，疊到中一刀正本上對著光源比對，量出偏移量，回頭調整 Window 座標，重印再比對，直到對齊為止——這是實務上最花時間的步驟，教材只能講方法，實際校準要在你自己的印表機上做

**紙張尺寸從哪裡設定？——這題新碰到的 SPAD Page Format**：`DINA4` 這種標準紙張規格是系統內建的，但中一刀連續紙的尺寸不是標準規格，要自己定義。已查證官方文件《Creating Page Formats》（SAP Printing Guide）——這是**傳統 Basis／列印管理的工具，不是 ABAP 開發工具，Claude 這邊完全沒有 API 可以查證或建立**，得靠你自己在 SAP GUI 操作：

- 路徑：`Tools → CCMS → Spool → Spool Administration`（交易碼 `SPAD`）→ `Full Administration` → `Device Types` 分頁底下的 `Page Formats`
- 官方文件明確提到**一個新 Page Format 要能用，需要連動建立三個關聯物件**：(1) **Page Format** 本身（定義紙張的寬高尺寸）、(2) 一個對應的 **Format**、(3) 該 Page Format 在目標印表機 **Device Type** 底下的 **Device Type Format**（把紙張尺寸換算成這台印表機認得的控制序列/escape sequence）——官方文件原文提醒：「Page Format 的名稱必須跟 Format 的名稱完全一致」，三個物件要一起建才能真正用起來
- ⚠️**這部分細節（每個畫面的確切欄位名稱）官方文件沒有寫到操作等級的細節，Claude 這邊也沒有系統可以實測**，比照這門課前面幾次「查證只能保證大方向、操作細節要靠你自己在畫面上確認」的教訓（見 `.claude/rules/sap-adt-mcp.md` 第 19 節與相關記憶），這題的 SPAD 操作只給**流程輪廓跟目標尺寸**，實際畫面上的欄位怎麼填，要請你比對系統的 F1 說明或請教熟悉 Basis 的同事
- **實務上優先要做的第一步：先確認系統是不是已經有現成的中一刀規格可以直接用**，不用自己從零建——很多系統已經預先為連續紙印表機準備好標準格式（例如對應 8.5"×11" 或 9.5"×11" 全刀的格式），只是可能還沒有半刀（5.5"）的版本，先用 `Page Formats` 清單搜尋一次比較保險

**本題目標尺寸：5.5 吋連續紙（中一刀）**（呼應基礎課 ex12 提過的同一種紙——ex12 是從「一頁幾行」LINE-COUNT 的角度提過它，這題是從「紙張實際尺寸」的角度處理）：

| 項目 | 英吋 | 換算公分 |
|---|---|---|
| 寬（連續紙標準寬度，含拖紙孔） | 9.5" | 24.13 cm |
| 高（中一刀＝整刀 11" 對半裁切） | 5.5" | 13.97 cm |

實際可列印區域會比這個數字略小（拖紙孔／邊界不可列印），建議先在 SPAD 用**整張紙的外緣尺寸**（9.5"×5.5"）定義 Page Format，Smartform 裡的 Window 座標再依實際量測到的可列印範圍去對齊，兩者不用是同一個數字。

## 學習目標

- 能講出「套表列印」跟 sf01～sf06「從零設計」的技術取向差異：只定位、不畫框線/標題
- 能清楚區分中一刀三聯複寫紙的物理複寫，跟 Smart Forms Copies Window 的邏輯重複列印，兩者完全不同層次
- 知道 SPAD Page Format／Format／Device Type Format 三個關聯物件的用途，能講出 5.5 吋中一刀連續紙對應的公分尺寸
- 能建立一組「不帶任何 Box/Shading，只精準定位」的 Window/Text，並知道套表校準是反覆試印比對的過程

## 事前準備

- 沿用 sf02 已建立的 Smart Style `ZSTY_02_LAYOUT`（`P2` 內文格式繼續用，不新建）
- 需要你在 `SPAD` 確認或建立中一刀尺寸的 Page Format（見 Lecture 的更正說明：Claude 無法建立/驗證這部分，且建議先查系統是否已有現成規格）
- 準備一份**模擬的中一刀套表版面**當練習對象（因為沒有真實客戶紙本，這題用下面這張文字示意圖模擬一張已經印好格線的簽收單）：

  ```
  ┌─────────────────────────────────────────┐  ← 紙張外緣 9.5"×5.5"
  │ 單據編號：____________  日期：________  │
  │                                           │
  │ 客戶：______________________________     │
  │                                           │
  │ 品名：______________  數量：____________ │
  │                                           │
  │                        簽收：____________ │
  └─────────────────────────────────────────┘
  ```

  （底線代表紙上已經印好的空格，Smartform 只需要把資料精準印在底線上方）

## 題目需求

1. **在 `SPAD` 確認／建立中一刀 Page Format**（先查有沒有現成的，沒有的話依 Lecture 說明的三個關聯物件建立），尺寸 9.5"×5.5"（24.13cm×13.97cm），命名建議 `ZSF07_HALF`（依你系統慣例調整）。

2. **建立新表單 `ZSF_07_OVERLAY`**，Style 指派既有的 `ZSTY_02_LAYOUT`，Page Format 選剛剛確認/建立的中一刀格式（不是 `DINA4`）。

3. **在 MAIN Window 裡，依照上面示意圖的空格位置，建立對應的 Text 節點**（每個都套用 `P2` 格式，**不設定任何 Box and Shading**）：

   | Text 節點 | 內容（先用固定字串測試，之後可比照 sf05 改成動態欄位） | 大約位置（依你的示意圖量測結果調整） |
   |---|---|---|
   | `TXT_DOCNO` | `A20260101001` | 單據編號底線正上方 |
   | `TXT_DATE` | `2026/01/01` | 日期底線正上方 |
   | `TXT_CUSTOMER` | `測試客戶股份有限公司` | 客戶底線正上方 |
   | `TXT_ITEM` | `測試品項` | 品名底線正上方 |
   | `TXT_QTY` | `10` | 數量底線正上方 |

   每個 Text 節點都是獨立的 Window 或同一個 Window 底下的獨立 Text（依你熟悉的方式皆可），重點是**位置要精準對齊、不要有任何框線**。

4. **啟用**整組物件。

5. **呼叫端程式**：Claude 建立 `ZR_SF07_DEMO`，沿用前六題骨架，`formname = 'ZSF_07_OVERLAY'`。

6. **校準驗證**（這步驟主要靠你自己操作）：
   - 先在一般 A4 紙上印出這張表單的 Print Preview 或實際列印
   - 疊到中一刀模擬紙本（或直接對著上面的示意圖）比對每個資料是不是精準落在底線上方
   - 沒對齊的話，回頭調整對應 Text 節點所在 Window 的 Position，重印再比對

## 思考題

1. 如果客戶要求「正本印公司抬頭章的浮水印文字、副本不用印」，這個需求該用什麼機制？（提示：這才是真正該用 sf02 教過的 Copies Window 的情境，跟這題的「三聯同時複寫」是不同需求，想想兩者怎麼分工）
2. 這題示範的 5 個 Text 節點都是靜態字串。如果要接上 sf05 教過的 Form Interface + 動態資料，需要做哪些修改？（提示：不用整個重做，只是把固定字串換成 `&工作區-欄位名&`）
3. 為什麼套表列印不能像 sf04 那樣加 Box and Shading？如果不小心手滑加了框線，實際列印到中一刀紙本上會發生什麼視覺問題？

## 答案

`ZR_SF07_DEMO` 快照見 `zr_sf07_demo.prog.abap`（已建立、語法檢查通過）。`ZSF_07_OVERLAY` 表單本體與 `SPAD` 的中一刀 Page Format 都需要你在 SAP GUI 手動建立（原因見 sf01／`.claude/rules/sap-adt-mcp.md` 第 19 節，SPAD 又比 Smartform 本體更進一步——連 Basis 系統管理領域都沒有 ADT API 可查證）。完成後請回報結果，或執行 `ZR_SF07_DEMO` 搭配 Print Preview／實際列印，比對中一刀模擬紙本確認校準結果。
